## What I'm building

- **[Kokobubu](https://github.com/aobasar/kokobubu)** — an iPhone AR guide: point at a device,
  ask out loud, and it marks the control and checks your work. Built solo for the Meta Global
  AI Developer Hackathon. [Demo video](https://www.youtube.com/watch?v=xyJxzW4g8xU)
- **[QRstudio](https://github.com/aobasar/QRstudio)** — a brand-aware QR code generator that
  decodes its own output, so it tells you when a design stops being readable.
- **[Clawdmoji](https://github.com/aobasar/Clawdmoji-clawd-inspired-mascot)** — a fan project
  inspired by Clawd from Claude Code: a cursor-following pixel buddy and 259 Clawdmojis, with
  sticker packs for WhatsApp, Telegram, Slack and Discord. GPL-3.0.
- **AI7Stack** — my company, founded November 2026, where I build AI tools and systems that hold
  up. [ai7stack.com](https://ai7stack.com)

Most of my work lives in private repos: tools I run on my own machines and servers every day,
like a prompt library with five AI providers behind a fallback chain, a Mac dictation app, and
a local-AI archive for meeting recordings. Happy to walk through any of it.
